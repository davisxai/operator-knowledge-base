# First prompts for find-skills

Five prompts to run after installing. Each one names a domain and a task, which is what the search needs to return a strong match. Type them into Claude Code as written, or swap the task for yours.

```
Find a skill for mobile app design.
```

```
Find a skill for writing integration tests in this project.
```

```
Is there a skill for reviewing pull requests before I merge?
```

```
Find a skill for processing PDFs and extracting structured data.
```

```
I keep writing SQL migrations by hand. Is there a skill that can take this over?
```

When Claude proposes a match, it shows the install count and the source repo. Read the skill's SKILL.md on GitHub before approving. Approve, and it installs into `.claude/skills/` without a restart.
