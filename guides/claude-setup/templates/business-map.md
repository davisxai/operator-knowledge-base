# Business map: [Business]

The operating facts. What you sell, what it costs, how a job moves from first contact to done, and what the client owns at the end. Every quote, proposal, and scope gets checked against this page, so a number that is not on it does not exist.

## The prompt that writes this file

Attach what you already have: the website, the price list, two or three recent proposals or invoices, and a contract if you use one. Then paste this into a chat inside the project.

```
Here are our website, price list, recent proposals, and the contract. Write the business map using the headings in business-map.md.
Rules: only facts that appear in what I gave you. If a heading has no source, write "TBD" under it and list the question I need to answer.
Prices exactly as written, with currency. No ranges you made up. No guarantees we did not state.
```

Fill in every TBD by hand. This is the one file where a guess costs money.
