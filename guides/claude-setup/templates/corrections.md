# Corrections: [Business]

One entry per mistake. What Claude did, what you wanted, and why. Claude reads this file at the start of every chat, so a mistake logged once is not made again.

## How an entry gets written

When a draft is wrong, say so in the chat and ask for the entry:

```
That is wrong. Write the corrections.md entry: what you did, what I wanted, why.
```

Copy the entry to the bottom of this file, then replace the file in the project's Context so the next chat reads it.
