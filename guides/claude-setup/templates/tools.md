# Tools: [Business]

Every tool the business runs on, what lives in each, and whether it is connected to Claude. Section 7 of the guide takes this list into the Connectors directory. Once a tool is connected, Claude reads it live instead of asking you to paste from it.

## The prompt that writes this file

If Gmail and your calendar are already connected, paste this as it is. If not, write the list by hand from the checklist below.

```
Read my sent mail and my calendar from the last ninety days. List every app, service, or website the business uses: anything I link to, log in to, send invoices from, book through, or share files with.
For each one write what lives in it in five words or fewer. Use the headings in tools.md.
```

Then walk the list through Customize, Connectors, Discover in the Claude desktop app and mark each one connected or not.
