# Character bible: [Your Name]

How you write, taken from things you already wrote. Claude reads this before it writes a word for you, so a reply or a proposal sounds like you and not like a template.

## The prompt that writes this file

Two ways to give Claude your writing. Pick one.

- **Gmail connected** (section 7 of the guide): paste the prompt as it is. Claude reads your sent mail through the connector.
- **No connector yet:** copy twenty emails you sent to clients into the chat first, then paste the prompt. Replace the first line with "Here are twenty emails I wrote."

```
Read the last sixty emails I sent. Skip newsletters and anything automated.
Write my character bible from them, using the headings in character-bible.md.
Rules: every example is a line I actually wrote, quoted. Nothing invented.
Where my habits differ by situation (a new lead, a current client, a late payment, saying no), say so.
```

Paste the result under the headings below. Cut anything that is not you. If an example line is not one you wrote, delete it.
