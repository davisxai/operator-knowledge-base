# memory/

Every correction, written once. When a draft misses, the fix becomes a file here. Claude reads this folder before the next draft, so the same miss does not come back.

One file per correction. Name it after the rule, kebab-case. Copy `_template.md` to start one. Add a line to the index below.

Created YYYY-MM-DD.

## Index

- no-copywriter-cliches.md. Never use copywriter metaphors. State the literal claim.
